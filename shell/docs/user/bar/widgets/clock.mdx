Displays the current time.

| Setting           | Type   | Default    | Description                                                                                                                                                                                                                 |
| ----------------- | ------ | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `format`          | string | `{:%H:%M}` | Clock format string for horizontal bars and vertical fallback. Use `\n` for multiple lines; examples: `{:%H:%M}\n{:%d/%m}`, `%H:%M`, `{:%-I:%M %p}`. See [Date format tokens](/noctalia/configuration/date-format-tokens/). |
| `vertical_format` | string | `""`       | Format used when the bar is vertical. When empty, falls back to `format`. A result with no line break stacks each `:`- or space-separated part on its own line. Supports the same syntax as `format`.                                                                            |
| `tooltip_format`  | string | `""`       | Optional format shown when mouse is hovered over the clock widget. This utilizes the same [date format tokens](/noctalia/configuration/date-format-tokens/) as format.                                                      |
| `timezone`        | string | `""`       | Optional timezone identifier (e.g. `Europe/Berlin`, `UTC`) to use for this clock. If empty, uses the system's local time.                                                                                                   |
| `stack_style`     | string | `"compact"` | For a two-line format: `compact` shows a smaller second line, both centred; `even` shows both lines at 12 px, aligned to the trailing edge (the Windows taskbar clock). |

```toml
[widget.clock]
format = "{:%H:%M}\n{:%d/%m}"
vertical_format = "{:%H\n%M}"
tooltip_format = "{:%A, %B %d, %Y}"

[widget.clock-12h]
type   = "clock"
format = "{:%-I:%M %p}"

[widget.clock-seconds]
type   = "clock"
format = "{:%H:%M:%S}"
vertical_format = "{:%H\n%M\n%S}"
```
