GTK 3, GTK 4 (libadwaita), Qt (qt6ct), KDE applications and the fcitx5 candidate panel take their colors from the
desktop's design tokens. No template needs to be enabled.

## How it works

- The package installs one generated file per toolkit and scheme: `andromeda/gtk/andromeda-gtk{3,4}-{light,dark}.css`,
  `qt6ct/colors/andromeda-qt-{light,dark}.conf`, `color-schemes/Andromeda{Light,Dark}.colors` and
  `fcitx5/themes/andromeda-{light,dark}/` under `/usr/share`.
- The shell writes `~/.config/gtk-3.0/andromeda.css` and `~/.config/gtk-4.0/andromeda.css`: an import of the current
  scheme's file plus the live accent. Your `gtk.css` imports it once, on its first line, so your own rules still win.
- For Qt it writes `~/.config/qt6ct/colors/andromeda.conf` and points qt6ct at it. For KDE apps it merges the scheme's
  colors and the accent into `~/.config/kdeglobals`. fcitx5 follows the light/dark setting and the accent itself.
- GTK 3 apps also switch between `adw-gtk3` and `adw-gtk3-dark` when that theme is installed.
- libadwaita apps read the light/dark scheme, accent, contrast and reduced motion from the settings portal.

The shell rewrites these files on each theme or accent change. To stop it, set `[theme] toolkit_themes = false`
(Settings: Appearance, "Theme GTK, Qt and KDE Apps"); the shell then removes its `gtk.css` import.
