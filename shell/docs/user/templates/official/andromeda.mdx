The built-in Andromeda template generates colors for regular and scratchpad borders,
the insertion hint, fullscreen backdrop, and overview tint.

## Setup

Enable **Andromeda** under **Settings → Appearance → Style → App Theming**.

Noctalia writes the rendered template to `~/.config/andromeda/noctalia.toml` and adds
it to the `files` array in the `[include.optional]` section of `config.toml`. Existing include
entries are preserved. Andromeda reloads both files automatically when they change.
